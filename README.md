# Kalo

KI-gestützter Kalorien- und Makro-Tracker: Foto vom Essen, Barcode-Scan, schnelle Offline-Suche und ein adaptiver Ziel-Coach.

> 🚧 In Entwicklung. Die vollständige Setup-Anleitung folgt mit Meilenstein 10.

```bash
pnpm install
pnpm test        # Kernlogik-Tests
pnpm --filter @kalo/mobile start   # Expo Dev-Server
```

Siehe [`docs/`](docs) für Architektur, Formeln und Entscheidungen.
